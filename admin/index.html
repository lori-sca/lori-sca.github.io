Site editor

Edit your sites' words the way you'd edit a blog — pick a site, pick a page, change the text, publish. The key below stays in this browser only, and is sent only to GitHub. I never see it.

1 · Create the key (one time)

  1. On GitHub: profile photo → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name it site-editor. Repository access: Only select repositories → tick lori-sca.github.io, lorisca-analytics.github.io, and lorisca-builds.github.io.
  3. Under Repository permissions, set Contents to Read and write. Generate the token and copy it.

2 · Paste it here

Site editor

Pick a site, then a page. Edit the words, hit Save — live in about a minute. An embed link under any text plays a YouTube video inline, or becomes a link card for anything else.
